# CodeSandbox Homepage

Source: [CodeSandbox](https://codesandbox.io/). Raw capture: [raw/codesandbox-homepage.md](../../raw/codesandbox-homepage.md).

## Summary

The CodeSandbox homepage presents [[codesandbox]] as infrastructure for instantly creating isolated cloud development environments. The page's current emphasis is programmatic sandbox creation for AI agents, code playgrounds, secure code interpretation, evals, CI/CD, and scalable developer or student environments.

It also states that CodeSandbox is now part of [[together-ai]], linking that move to the launch of the CodeSandbox SDK and code interpretation for generative AI.

## Key Takeaways

- CodeSandbox is positioned as a cloud sandbox platform, not only as a browser-based coding workspace.
- The central technical promise is isolated environments that can safely run arbitrary or untrusted code.
- The product emphasizes APIs and SDK-driven creation of environments, which makes it relevant to AI agents and automated code execution systems.
- The homepage claims microVM-based startup, cloning, and snapshot restoration with fast resume behavior.
- The platform supports hibernation and resumption, suggesting a cost-control model for intermittent development or CI workloads.
- Major listed use cases include AI agents, development environments at scale, secure code interpretation and evals, and CI/CD.
