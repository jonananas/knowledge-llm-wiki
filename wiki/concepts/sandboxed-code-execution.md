# Sandboxed Code Execution

Sandboxed code execution is the practice of running code inside an isolated environment so it cannot affect the host system or other workloads. It is especially relevant when code is untrusted, generated by an AI system, submitted by users, or run at high volume.

The [[codesandbox-homepage]] source positions [[codesandbox]] around this need: isolated environments for AI agents, secure code interpretation, evals, CI/CD, and large-scale development environments.

## Design Concerns

- Isolation between workloads.
- Fast startup and teardown.
- Snapshotting and resume behavior.
- Lifecycle controls such as hibernation.
- APIs that let products create and manage environments automatically.
- Compatibility with real development workflows, not only tiny code snippets.
