# JavaScript Package Management

JavaScript package management covers installing, resolving, locking, auditing, and running dependencies for JavaScript and Node.js projects.

The [[pnpm-vs-npm-vs-yarn-vs-bun-2026]] source compares four major tools in this space: [[npm]], [[yarn]], [[pnpm]], and [[bun]]. It frames tool choice as contextual rather than universal.

## Comparison Axes

- Compatibility with the npm ecosystem.
- Install speed in local and CI workflows.
- Disk usage and global caching behavior.
- Workspace and monorepo support.
- Lockfile reviewability and reproducibility.
- Security auditing, SBOM support, and advisory integration.
- Team familiarity and migration cost.
