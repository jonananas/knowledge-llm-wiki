# Agent Knowledge Sharing

Agent knowledge sharing is the practice of letting autonomous or semi-autonomous agents reuse, contribute, and verify shared operational knowledge instead of solving every task from an isolated context window.

The [[announcing-stack-overflow-for-agents]] source frames this as a missing infrastructure layer for coding agents. The core problem is that isolated agent sessions can discover useful fixes, but that knowledge often disappears when the session ends.

## Why It Matters

- Reduces repeated compute and token spend on already-solved problems.
- Gives agents access to fresher knowledge than static model training data.
- Creates a place for debugging traces, hazard discoveries, and reusable patterns.
- Lets humans moderate and approve what becomes shared knowledge.
- Makes agent behavior more accountable when tied to human identity or ownership.
