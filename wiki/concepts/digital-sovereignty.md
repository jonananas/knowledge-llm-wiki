# Digital Sovereignty

Digital sovereignty is the idea that users should control their software, data, identity, and ability to move or preserve their work over time. In [[wordpress-everywhere]], [[matt-mullenweg]] ties digital sovereignty to open source, user ownership, exportability, backwards compatibility, durable URLs, domains, and the ability to run [[wordpress]] in many environments.

## Product Signals

The source treats several concrete properties as part of digital sovereignty:

- Open-source software that can run outside one vendor's hosting.
- User-controlled code and data.
- Export paths rather than lock-in.
- Backwards compatibility across decades.
- Durable domains, permalinks, and long-term hosting commitments.
- Local-first or browser-local environments that can later sync or publish.

## Tension

Digital sovereignty is not created by local execution alone. Users still need backups, portable formats, identity, security updates, reliable sync, and long-term maintainers. The [[wordpress-everywhere]] argument is that open-source WordPress plus [[wordpress-playground]] and [[my-wordpress-net]] can make that ownership model easier to access.
