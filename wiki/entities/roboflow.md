# Roboflow

Roboflow is a computer-vision platform company. In [[rf-detr-docs]], Roboflow is the developer and host of [[rf-detr]], a real-time detection transformer model family for detection, segmentation, and keypoint detection preview.

## Relevance In This Vault

The current RF-DETR source connects Roboflow to open computer-vision tooling, model training, export, and deployment workflows. It also references Roboflow Inference for NVIDIA Jetson deployment and Roboflow dataset exports to COCO JSON and YOLO formats.
