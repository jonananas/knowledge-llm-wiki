# npm

npm is the default package manager shipped with Node.js. In [[pnpm-vs-npm-vs-yarn-vs-bun-2026]], it is positioned as the compatibility-first choice: rarely the fastest or most disk-efficient, but still the lowest-surprise option for legacy, enterprise, and broadly compatible workflows.

## Role

npm matters because it is the ecosystem baseline. Alternative package managers are usually judged by whether they preserve npm package compatibility while improving speed, disk usage, workspace behavior, or security workflow.
