# WordPress

WordPress is an open-source publishing platform and content-management system co-founded by [[matt-mullenweg]]. In the [[wordpress-everywhere]] source, Mullenweg argues that [[wordpress-playground]] and [[my-wordpress-net]] expand WordPress from hosted CMS software into a portable software environment that can run locally in the browser.

## Role

For this vault, WordPress matters as a long-lived open-source platform whose value proposition is shifting from "publish a website" toward a broader ownership model: local experimentation, browser-based personal workspaces, AI-assisted customization, exportability, cloud publishing, and long-term durability.

## Relevant Claims From The Source

- WordPress can now run in browser-local environments through [[wordpress-playground]].
- Local instances make experimentation, rollback, and AI-assisted changes easier.
- Mullenweg frames WordPress as part of [[digital-sovereignty]], not only publishing.
- Backwards compatibility and exportability are central to the trust argument.
