# CodeSandbox

CodeSandbox is a developer tooling platform for creating isolated cloud development environments. Its homepage currently emphasizes programmatic sandboxes for AI agents, secure code execution, evals, CI/CD, and scalable development environments. [[codesandbox-homepage]]

## Product Positioning

CodeSandbox historically has been associated with browser-based coding and shareable code sandboxes, but the current homepage foregrounds infrastructure: APIs for spinning up isolated environments that can run code safely and at scale.

## Capabilities Highlighted

- Programmatic sandbox creation through APIs and the CodeSandbox SDK.
- Isolated environments for running arbitrary or untrusted code.
- MicroVM-based startup, cloning, and snapshot restoration.
- Continuous context through snapshots and auto-resume.
- Customizable hibernation for idle environments.
- Use cases for AI agents, development environments at scale, secure code interpretation, evals, and CI/CD.
