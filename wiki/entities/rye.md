# Rye

Rye is an experimental Python project and package management tool originally created by Armin Ronacher. Astral announced in February 2024 that it was taking stewardship of Rye while building [[uv]] into a unified successor project. [[astral-uv]]

## Relevance

In the `uv` launch post, Rye matters less as a standalone tool and more as a design lineage and migration concern. Astral said it would maintain Rye, migrate it toward using `uv` under the hood, and treat it as an experimental testbed for the higher-level project-management experience that `uv` is meant to grow into.
