# my.WordPress.net

my.WordPress.net is a browser-local WordPress environment built on [[wordpress-playground]]. In [[wordpress-everywhere]], [[matt-mullenweg]] describes its soft launch as evidence that WordPress should be understood as portable, user-controlled software rather than only something acquired through a host.

## Product Model

The WordPress.org announcement describes my.WordPress.net as persistent WordPress in the browser with no sign-up, hosting plan, or domain decision required before use. It is private by default and not reachable from the public internet.

Example app-like starting points include:

- Personal CRM.
- Personal RSS reader.
- AI workspace and knowledge base.

## Operational Boundaries

- Storage starts at roughly 100 MB.
- Data stays in the browser.
- Each device has a separate installation.
- Users should download backups regularly.
- Publishing and sync are separate future or adjacent steps, not the default local mode.
