# PhysAg3D

PhysAg3D is a research project and released agent-assisted workflow for generating interactive 3D assets from a single image. It combines a pretrained 3D generator's textured mesh with agent-built parts, joints, compliant regions, and bindings between physical structures and visible surfaces. [[supra-3d-physag3d]]

The released repository provides controller and worker tools, examples, tests, checksums, and provenance records. Running a new case needs external GPU-hosted models and geometry/simulation tooling. Its delivery report distinguishes simulated, animated, and static outcomes; successful execution alone does not prove physical correctness. [[supra-3d-physag3d]]
