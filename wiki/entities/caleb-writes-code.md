# Caleb Writes Code

Caleb Writes Code is the creator of [[graph-engineering-explained-in-8min]], a short video explaining multi-agent workflow graphs through a staged research example. The video's argument is that stronger individual agents make graph orchestration more useful, while parallel work raises token and coordination costs.
