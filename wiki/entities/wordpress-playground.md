# WordPress Playground

WordPress Playground is the WebAssembly-powered platform for running WordPress without a traditional host. In [[wordpress-everywhere]], it is the technical basis for [[my-wordpress-net]] and for the claim that WordPress can become browser-local software rather than only hosted CMS software.

## Capabilities From The Source

- Runs a web server, database, and WordPress in the browser.
- Can start a full WordPress installation quickly enough for experimentation.
- Enables local, private, disposable instances.
- Supports composable and atomic changes that can be tracked and rolled back.
- Makes WordPress practical as a target for AI-assisted code changes, plugin modification, testing, and demos.

The WordPress.org Playground page also positions Playground for browser, Node.js, mobile apps, VS Code, embedded demos, pull-request previews, site cloning, version testing, and app-store style distribution. [[wordpress-everywhere]]

## Relationship To Sandboxing

Playground is related to [[sandboxed-code-execution]], though its scope is narrower than a general cloud sandbox. It gives WordPress-specific isolation and fast setup for experimentation, QA, demos, and AI-assisted changes.
