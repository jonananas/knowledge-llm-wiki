# Fumadocs Homepage

Source URL: https://www.fumadocs.dev/
Published: homepage, no publication date shown
Captured: 2026-08-26

Fumadocs presents itself as a React.js documentation framework for building customizable documentation sites. The homepage emphasizes polished defaults, a headless/composable architecture, Markdown and MDX authoring, framework portability across React ecosystems, and integration with arbitrary content sources.

## Main Points

- Fumadocs describes itself as a React.js documentation framework for developers, designed by Fuma Nama.
- The getting-started command is `pnpm create fumadocs-app`, with project setup options shown for Next.js, Waku, TanStack Start, and React Router.
- The homepage frames the product as "headless docs": a set of blocks developers compose rather than a rigid full-site template.
- It offers designed themes plus a headless mode for plugging in custom UI.
- Fumadocs supports Markdown and MDX, aiming to work for non-developer writers, developers, and AI agents.
- Markdown features highlighted include images, syntax highlighting through Shiki, codeblock groups, callouts, cards, custom heading anchors, and automatic tables of contents.
- MDX features highlighted include JavaScript and JSX syntax, custom components, include/embed content, TypeScript Twoslash, Shiki notations, Storybook integration, and remark/rehype extension points.
- It can use React Server Components to keep docs content connected to live server-side data such as databases, CMSs, type definitions, or OpenAPI playgrounds.
- The architecture is described as separated into Content, Core, and UI layers.
- The package ecosystem includes `fumadocs-mdx`, `fumadocs-core`, `fumadocs-ui`, `fumadocs-openapi`, and `fumadocs-obsidian`.
- Fumadocs is designed to adopt different content sources including MDX, Content Collections, and custom CMS integrations such as BaseHub, Sanity, and Payload.
- Search integrations mentioned include Orama Search and Algolia Search.
- Fumapress is presented as a simpler React.js framework for Fumadocs, using plugins for people who want a working docs setup with less configuration.
- The project states that it is open source and community powered.

## Strategic Framing

Fumadocs is positioned for teams that want documentation UX and tooling without rebuilding the whole docs stack for each project. The core tradeoff it advertises is strong defaults plus deep customizability: developers can use its complete UI, customize generated components, or drop down to headless libraries.
